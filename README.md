# GamerShop

Proyecto React + Vite.

## Arrancar

```bash
npm install
npm run dev
```

Abre la URL mostrada por Vite, normalmente `http://localhost:5173`.

## Build

```bash
npm run build
npm run preview
```

## Admin

Contraseña de demo: `gamershop2026`

Los productos, carrito y sesión administrativa usan `localStorage`.
